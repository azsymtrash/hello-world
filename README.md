# CallScribe

Android приложение, което записва телефонни разговори и чете текстови съобщения,
транскрибира ги, извлича от тях конкретни задачи с краен срок чрез Claude и ги
подрежда в **таблица с колони и напомняния**.

---

## Какво реално прави

| Стъпка | Как |
|---|---|
| Засича начало и край на разговор | `AccessibilityService` + `TelephonyCallback`, плюс `PHONE_STATE` broadcast |
| Записва аудиото | Foreground услуга с `MediaRecorder` (AAC/M4A, 16 kHz моно) |
| Чете съобщения | `SMS_RECEIVED` broadcast + еднократен внос от системната база |
| Превръща аудиото в текст | HTTP към OpenAI-съвместим `/v1/audio/transcriptions` (whisper.cpp, faster-whisper, OpenAI) |
| Извлича задачите | Claude Messages API със структуриран изход (tool use) |
| Показва ги | Сортируема таблица + експорт в CSV |
| Напомня | `AlarmManager` + известие с бутони „Готово“ и „Отложи 1 час“ |

Колони в таблицата: Създадено · Източник · Контакт · Задача · Краен срок ·
Приоритет · Статус · Увереност. Всяка колона се сортира с натискане на
заглавието; редът се отваря за редакция.

---

## Ограничения, които не мога да заобиколя

Това не са пропуски в кода, а ограничения на Android и на правилата за приложения.

1. **Аудиото на отсрещната страна.** От Android 10 `AudioSource.VOICE_CALL` е
   недостъпен за приложения извън системните. Услугата опитва наличните
   източници по ред и на повечето телефони реално пише през микрофона.
   **Отсрещната страна се чува ясно само при включен високоговорител** — затова
   има настройка, която го включва автоматично.
2. **Google Play ще откаже приложението.** Записът на разговори е изрично
   забранен, а `READ_SMS` се дава само на приложения, които са SMS клиент по
   подразбиране. Приложението е за инсталиране от APK на собствен телефон.
3. **iOS е невъзможен.** Няма API за достъп до аудио на разговор — нито
   публичен, нито заобиколен.
4. **Съдържанието напуска телефона.** Транскрипцията и анализът се изпращат към
   сървърите, които си конфигурирал. Ако това не е приемливо, вдигни
   whisper.cpp сървър в локалната си мрежа и посочи неговия адрес.
5. **API ключът не се пази криптирано.** Стои в `SharedPreferences`. Правилният
   вариант за реална употреба е собствен прокси сървър, който държи ключа, а в
   приложението се въвежда само неговият адрес.
6. **Правно.** В България записът на собствен разговор е допустим,
   разпространението му без съгласие — не. В други държави се изисква съгласие
   на всички страни. Приложението показва екран за съгласие при първо пускане;
   отговорността за употребата е на потребителя.

## Билд

В хранилището има GitHub Actions workflow, който произвежда APK при всяко
качване (`Actions` → последният build → артефакт `callscribe-debug-apk`).

Локално:

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

Нужни са JDK 17 и Android SDK (compileSdk 35, minSdk 26).

## Настройка след инсталиране

1. Приеми екрана със съгласието и разреши исканите разрешения.
2. **Настройки → Настройки за достъпност** → включи „CallScribe“. Без това
   автоматичният запис не тръгва надеждно на Android 12+, защото фонов broadcast
   няма право да стартира услуга с микрофон.
3. Разреши точни аларми и изключи оптимизацията на батерията — иначе
   напомнянията закъсняват.
4. **Анализ (Claude):** адрес `https://api.anthropic.com`, твоят API ключ, модел
   `claude-sonnet-5` (или `claude-opus-5` за по-точно извличане,
   `claude-haiku-4-5` за по-евтино).
5. **Транскрипция:** адрес на whisper-съвместим сървър, напр.
   `http://192.168.0.10:8080`, модел `whisper-1`, език `bg`.
6. Включи „Записвай разговорите“ и/или „Чети входящи съобщения“.

Без конфигуриран сървър за транскрипция разговорите се записват, но остават
непреработени — виждат се в раздел „Източници“ с обяснение за грешката.
Текст може да се подаде и ръчно за анализ, без никакъв запис.

## Структура

```
app/src/main/java/com/callscribe/
├── CallScribeApp.kt          канали за известия
├── data/                     Room: Capture (източник) и TaskRow (ред в таблицата)
├── capture/                  услуга за запис, следене на разговори, SMS
├── ai/                       транскрипция и извличане на задачи с Claude
├── work/                     WorkManager: транскрипция → анализ → напомняния
├── reminder/                 AlarmManager, известия, възстановяване след рестарт
├── export/                   CSV
└── ui/                       Compose: таблица, източници, настройки, съгласие
```

Данните се пазят само локално, в частната памет на приложението
(`/data/data/com.callscribe`). Няма акаунти, синхронизация и телеметрия.
