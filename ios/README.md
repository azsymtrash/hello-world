# CallScribe за iOS

SwiftUI приложение, което записва срещи и приема текстове, транскрибира ги,
извлича задачи чрез Claude и ги подрежда в същата таблица с напомняния като
Android версията.

---

## Прочети това преди всичко останало

iOS **не може** да прави основното, за което е писана Android версията:

| | Android | iOS |
|---|---|---|
| Автоматичен запис на телефонен разговор | да, през микрофона | **невъзможно** |
| Запис по време на разговор изобщо | да | **невъзможно** — системата отнема микрофона |
| Автоматично четене на SMS | да | **невъзможно** — няма достъп до Съобщения |
| Запис на срещи и гласови бележки | да | да |
| Приемане на текст през бутона за споделяне | — | да |
| Транскрипция, анализ, таблица, напомняния | да | да |

Това не са пропуски в кода — Apple не предоставя такива API на никого.

---

## Език

Интерфейсът следва езика на телефона: български при българска система, английски
при всичко останало. Преводите са в `App/Resources/bg.lproj/Localizable.strings`;
ключовете са самите английски надписи.

Настройката **Език** в приложението е отделно нещо — тя казва на какъв език е
съдържанието, тоест какво да очаква сървърът за транскрипция и на какъв език
моделът да пише задачите.

## Билд

Нужни са macOS, Xcode 15 или по-нов, и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
cd ios
xcodegen generate
open CallScribe.xcodeproj
```

В Xcode: избери проекта → target `CallScribe` → **Signing & Capabilities** →
избери своя Team. Същото за target `CallScribeShare`. После Cmd+R с включен
телефон.

**Ако акаунтът ти е безплатен (без Apple Developer Program):** App Groups не се
поддържат и разширението за споделяне няма да се подпише. Тогава махни
`CallScribeShare` от `dependencies` в `project.yml`, изтрий реда
`CODE_SIGN_ENTITLEMENTS` от target `CallScribe`, генерирай наново и билдни само
основното приложение. Всичко освен бутона за споделяне работи; текст се вкарва
през „Добави текст“ и „Постави от клипборда“.

### Без XcodeGen

Ако не искаш да инсталираш XcodeGen: File → New → App в Xcode, име `CallScribe`,
интерфейс SwiftUI, storage None, минимална версия iOS 17. После издърпай папката
`App/Sources` в проекта и добави ключа `NSMicrophoneUsageDescription` в Info.

## Настройка след инсталиране

1. Приеми екрана със съгласието.
2. Разреши известията и микрофона, когато телефонът попита.
3. **Настройки → Анализ (Claude):** адрес `https://api.anthropic.com`, твоят API
   ключ, модел `claude-sonnet-5`.
4. **Настройки → Транскрипция:** адрес на whisper-съвместим сървър, модел
   `whisper-1`, език `Български` (или `English`). Без него записите остават
   непреработени, но текстът работи.

## Как се ползва

- **Запиши среща** — записва през микрофона; анализът тръгва сам при спиране.
- **Добави текст** или **Постави от клипборда** — за съобщения и бележки.
- **От Съобщения:** натисни и задръж съобщението → Сподели → CallScribe.
- Таблицата се отваря на първия таб. Отметката вляво маркира задача като
  направена с едно натискане и отменя напомнянето.
- Известието носи бутони „Готово“ и „Отложи 1 час“ — работят, без да отваряш
  приложението.
- Бутонът за споделяне горе вдясно изнася видимите редове в CSV.

## Структура

```
ios/
├── project.yml              спецификация за XcodeGen
├── App/
│   ├── Info.plist
│   ├── CallScribe.entitlements
│   └── Sources/
│       ├── CallScribeApp.swift      вход и обработка на известията
│       ├── Models/                  SwiftData: Capture и TaskRow
│       ├── Storage/                 настройки, пътища, обща пощенска кутия
│       ├── Services/                транскрипция, Claude, напомняния, запис, CSV
│       └── Views/                   таблица, източници, настройки, съгласие
└── Share/                   разширение за бутона „Сподели“
```

Данните стоят само на телефона. Няма акаунти, синхронизация и телеметрия.
